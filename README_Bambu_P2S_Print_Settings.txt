Custom Igloo-Style Can Holder with Front Logo
File: custom_igloo_can_holder_logo_Bambu_P2S.stl
Units: millimeters
Printer target: Bambu Lab P2S / Bambu Studio

Recommended import:
1. Open Bambu Studio.
2. File > Import > Select custom_igloo_can_holder_logo_Bambu_P2S.stl.
3. Make sure units are millimeters.
4. Place flat on the build plate.
5. Rotate so the logo faces the front if desired.

Recommended print settings:
- Nozzle: 0.4 mm
- Layer height: 0.20 mm
- Filament: PETG, PLA+, or matte PLA
- Walls: 4
- Top/Bottom shells: 5
- Infill: 15-20%, gyroid
- Supports: On, tree supports recommended because side clips may need support
- Seam: Back
- Build plate: Textured PEI

Sizing:
- Inner can opening is approximately 69 mm diameter.
- Designed for standard 12 oz aluminum cans.
- If your cans fit tight, scale X/Y to 101% in Bambu Studio.
- If your cans fit loose, scale X/Y to 99%.

Finish tips:
- Print in matte black for the body.
- The logo is raised geometry. Paint the raised logo white/gray after printing, or use Bambu Studio color painting if printing with AMS.
- Light sanding on the raised logo edges will sharpen the look.
